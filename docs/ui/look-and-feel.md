# Look And Feel

## Current Direction
The current UI uses a restrained SaaS operations style:
- Light slate background.
- White content surfaces.
- Compact cards with 6px radius.
- Slate text and borders.
- Ink primary buttons.
- Accent color for route eyebrows and links.

## Strengths
- The app feels closer to an operations tool than a marketing site.
- Density is appropriate for a solo-operator work dashboard.
- The Board/Clients split gives a quiet, utilitarian rhythm.
- Native controls keep the MVP familiar.

## Visual Risks
- The palette is close to a one-note slate/blue-gray system; accent usage is sparse.
- Repeated cards-within-cards can make hierarchy muddy on dense pages.
- Many controls share similar weight, so destructive, primary, secondary, and navigation actions are not visually distinct enough.
- Client-facing screens currently share admin command-center language.
- No visual treatment exists for danger, warning, success, info, or AI-admin-only states.

## Direction
- Keep the calm operational base.
- Add semantic color roles sparingly: success, warning, danger, info, muted, accent.
- Use more table/list density for repeated operational rows and reserve cards for records, forms, and panels.
- Add status color chips that pass contrast and are not color-only.
- Use clearer destructive-action styling and confirmation UI.
